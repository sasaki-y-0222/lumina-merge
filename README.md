# 珠 LUMINA MERGE

コードだけで描くネオンの合体パズル。画像・音声アセットなし、単一HTML（WebGL2 + WebAudio）。

**遊ぶ:** https://sasaki-y-0222.github.io/lumina-merge/

## 遊び方
- 左右にドラッグして離すと珠が落下。同じ色の珠がふれると、ひとつ大きい珠に合体
- **目的1 クリア**: 11段階目のプリズム珠を作る（クリア時のスコアが少ないほど好記録）
- **目的2 エンドレス**: クリア後も続けて最高スコアを狙う
- ひび珠は合体せずに砕け、周りを吹き飛ばす（得点3倍）
- スキル: シェイク（キー1）／注水（キー2）。落とす数は ×1 / ×5 を切り替え可能
- PC: マウス、または ←→ と Space。Esc でメニュー
